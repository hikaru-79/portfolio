ECサイト
企画・開発プロジェクト

プロジェクト概要

Outline

プロジェクトリーダーとして、toB向けECサイトの立ち上げから、グループ顧客向けのモール型ECサイトの構築、商品企画・特集ページの制作、アクセス解析に基づく運用改善まで担当。「作る」ことにとどまらず、マーケティング視点を持った構築・運用を実施しました。

Target

【toB】 グループ法人の各拠点・店舗スタッフ（ノベルティやお茶菓子、手土産などに活用）
【toC】 スイーツ・食品・ギフトなど、上質な季節商品やこだわり商品を求める顧客

Period & Role

toB：Makeshop（HTML / CSS / JavaScript）
toC：WordPress（HTML / CSS / JavaScript / PHP）
担当領域：立ち上げ提案 / デザイン / 開発（MakeShop・WordPress） / 特集企画・商品提案 / 特集ページデザイン・コーディング

Purpose

【toB】 社内発注フローのデジタル化による業務効率化
【toC】 季節ごとの魅力的な特集展開と会員限定施策によるリピート率・客単価・売上向上
