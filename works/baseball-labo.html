BASEBALL LABO
ランディングページ

制作概要

Outline

室内野球練習場「ONECAGE」から発足した新規スクール事業「BASEBALL LABO」のSNSからの流入用ランディングページ。元プロ野球選手による最大3名の超少人数指導と、完全個室施設での自主練習を組み合わせた「確実に上達できる仕組み」を明確に伝え、体験レッスンから月額プランへの転換を最大化するページを制作しました。

Target

少年野球で打率・飛距離を伸ばしたい小中学生とその保護者、大人数スクールの指導に物足りなさを感じている選手、および本気で技術向上を目指す社会人プレーヤー

Period & Role

デザイン：2日（Figma / Photoshop）
コーディング：2日（HTML / CSS / JavaScript）
申し込み管理システム：2日（HTML / CSS / JavaScript / GAS）
担当領域：コンテンツ設計 / デザイン / コーディング / 申し込みフォーム・管理システム構築

Purpose

新規プロジェクトの認知確立、他社スクールとの圧倒的な差別化（元プロ直接指導 × 完全個室自主練環境）の訴求、および体験レッスン予約・公式LINE経由の問い合わせ獲得

内容詳細

Detail

「野球が変わる ― 本気で上手くなりたいならプロに学べ」
熱量とロジックを両立し、保護者・選手の納得感を生むLP設計。

ファーストビューでは、元プロ野球選手・北條史也氏を全面に押し出した力強いタイポグラフィと動画・ビジュアルを配置し、スクールの信頼性と本気度を瞬時に伝達。

単に「教えてもらう」だけではなく、「月2回のレッスン → ONECAGEでの自主練 → 月1回のランク認定テスト」という独自のサイクルを図解化。他社スクールとの比較表を設けることで、月謝以上の価値を保護者や受講検討者へ視覚的に納得してもらえるストーリーを構築しました。

スマートフォンからの申し込みが大半を占めるため、モバイルでの読みやすさとCTAボタン（LINE問い合わせ・体験予約）へのタップしやすさを徹底的に検証し、高いコンバージョン率を意識した実装を行いました。
